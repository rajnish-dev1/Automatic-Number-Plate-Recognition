# YOLO Model Weights

This folder stores trained YOLO
license plate detection models.

## Model File

Expected model filename:

license_plate_detector.pt

## Model Usage

The trained model is used to detect
vehicle number plates in images
and videos.

## Important

YOLO mode requires a custom-trained
license plate detection model.

Model weights are not included
in this repository.

Place your trained weights here
before running YOLO mode.
